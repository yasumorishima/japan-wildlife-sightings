# japan-wildlife-sightings

日本の自治体が公開している**クマ・イノシシ・シカ等の出没情報**を、
出典ごとにバラバラな形式のまま埋もれさせず、**共通スキーマの機械可読データセット**にそろえます。

- **地図で見る: https://yasumorishima.github.io/japan-wildlife-sightings/**
  （地理院タイルの淡色地図・空中写真と、NASA GIBS の前日の衛星画像を背景に切り替えられます）
- 収録データ: [`data/sightings.csv`](data/sightings.csv) / [`data/sightings.geojson`](data/sightings.geojson)
- 取得状況と品質: [`data/summary.json`](data/summary.json)
- 再配布可否の根拠: [`docs/licenses.md`](docs/licenses.md)
- Kaggle: [Japan Wildlife Sightings](https://www.kaggle.com/datasets/yasunorim/japan-wildlife-sightings)（`data/` と同じ収録範囲。毎日更新）

## なぜ作るのか

出没情報は各都道府県が公開していますが、**形式が県ごとに完全に別物**です。
CKAN の CSV、ArcGIS の Survey123、Google マイマップ、Excel、そして PDF。
環境省がまとめている全国値も PDF のみで、**全国の点データはどこにも存在しません**。

集約した商用サービスは複数ありますが、いずれもクローズドです。
研究・自治体・住民・農業関係者が自由に使える**開いた土台**が無いので、それを作ります。

## まだ取れていないもの

**クマが生息する 40 都道府県のうち、点データを機械可読で出しているのは 14 です。**
残る府県は PDF か HTML の表だけで公開しています。

PDF は **1 本ずつ中身が違います**。実際に落として測ったところ、岩手・秋田・青森・
茨城・島根・和歌山・兵庫のものは**月別の集計表や注意喚起**で、1 件ずつの記録では
ありませんでした。1 行 1 件の一覧だったのは長野県と山梨県です。

長野県ぶんは `pdf` アダプタで読めるようになりました（22 本の月別 PDF から 2,026 件）。
**ただし PDF に座標が無いので `lat`/`lon` は空で、市町村名までしか分かりません。**
山梨県はセルが複数行に折り返す様式で、桁揃えのテキストからは読めません。
`pdf_bbox` アダプタが `pdftotext -bbox-layout` の語の座標から行と列を組み直します
（751 件・日付を読めたのは 748 件）。列の位置は 1 ページ目の値の並びから学び、
以降のページでも同じ位置を使います。ページごとに作り直すと値の欠けたページで 1 列ずれ、
見出し行から作ると 1 件目の折り返し本文を巻き込みました（どちらも実際に起きました）。

### 県のページを見るだけでは足りない

富山県は県のページからは PDF しか辿れませんが、**ArcGIS Online を横断検索すると
公開の Survey123 レイヤが見つかり、4,614 件が取れました**。三重県・岡谷市も同じ経路です。
「PDF しか無い」と判定した県も、配信基盤の側から探すと出てくることがあります。
福島県（4,491 件）も同じ経路で見つかり、**県の公式ページのダッシュボードが同じレイヤを
参照していること**を確認して出典を確定しました。

検索するときは **語をひとつだけ**にしてください。`"福島 クマ"` のように県名を足すと
AND で絞られ、実際に存在するレイヤが返ってきません（この掃き方で一度取りこぼしました）。

2026-11-02 の掃き直しでは、**新潟県柏崎市のイノシシ目撃情報**（年度別 7 レイヤ・CC BY と明記）を見つけて収録し、
福岡県・会津若松市・都留市も取得できるようにしました（規約が確認できないので収録はしていません）。
福岡県は `mokugeki`（ローマ字）でしか出てこず、岡谷市は `choujyu` で全獣種の公開ビューが見つかりました。
`クマ` `bear` のような語は 1,000 件の上限で切れるので、ローマ字や「鳥獣」「目撃」も試してください。

### 実行元によって届かない公開元がある

同じ URL でも、**どこから取りに行くかで結果が変わります**。

- **石川県のカタログ（`ckan.opendata.pref.ishikawa.lg.jp`）は GitHub のランナーから 403**
  になります。User-Agent を変えてもトップページごと拒否されるので、IP による遮断です
  （応答は `server: awselb/2.0`）。配布元が拒否している取得はしないので、カタログ経由の 4 出典
  （石川県のクマ、金沢市のクマ・イノシシ・サル）は**凍結**しています。2026-08-29 に取得した内容のまま据え置き、
  日次では取りに行きません（`sources.json` の `frozen`、`summary.json` にも出ます）。
- **山梨県のサイトは GitHub のランナーから接続タイムアウト**します。
- **倉敷市と埼玉県のオープンデータの配布元は、GitHub のランナーからの取得を 403 で拒否**します。
  配布元が拒否している取得はしないので、この 2 つは収録していません（ライセンス上は再配布できます）。
- 山口県のカタログは**旧式の TLS しか持たない**ため、ランナーの既定の暗号方針では
  サーバ側が接続を拒否します（暗号の要求だけを緩めて取得しています。証明書の検証は緩めません）。

そのため、**収録している出典が取得できなかった回は、前回のデータをそのまま残します**。
1 つの公開元が届かないだけで、収録済みの数千件が消えるほうが害が大きいからです。
取得は通っても、前回の半分未満しか取れなかった回（カタログが 0 件を返した、年度別のファイルが 1 本取れなかった等）も、
取得できなかった回と同じに扱って据え置きます。
据え置いたことは `data/summary.json` の `reused_previous` と実行ログに必ず出ます。出典ごとに
最後に取れた日時（`last_success_at`）と、取れなくなった日時（`failing_since`）も記録し、
7 日以上続いた出典は実行ログに「要確認」として一覧にします。

### 重複について

新潟県は現行フォーム（2025 年度〜）と過去分（2017 年〜）の 2 レイヤがあり、**期間が重なる
ぶんは同じ出没が二重に入っています**。どちらも収録対象外なので `data/` には影響しませんが、
手元で両方を使うときは突き合わせが要ります。

## 地図

`docs/` に MapLibre GL JS の地図ページを置いています（GitHub Pages で公開）。
背景は**地理院タイル**（淡色地図・地図・シームレス空中写真）と
**NASA EOSDIS GIBS の VIIRS 前日画像**で、どちらも鍵が要りません。
獣種・区分・年で絞り込め、点をクリックすると状況と出典が出ます。

**収録しているのは 20 出典**で、うち**座標を持つ 16 出典が地図に出ます**
（秋田・京都・山口・石川・東京・岐阜・札幌市・室蘭市・石狩市・上砂川町・森町・仙台市・柏崎市・長岡市・裾野市・白石市。金沢市の 3 出典と宮城県の令和8年度分は町名・地区名までで座標がありません）。
他県はデータを載せていないので、その範囲を拡大しても点は出ません。
ライブラリと字形は同梱してあり（`docs/vendor/`）、外部 CDN には依存しません。
表示すべき出典は [`docs/THIRD-PARTY-NOTICES.txt`](docs/THIRD-PARTY-NOTICES.txt) にまとめています。

```bash
python3 build_map.py            # docs/data/sightings.min.geojson を作り直す
python3 -m http.server -d docs  # 手元で見る
```

## 使い方

```bash
python3 collect.py                    # 全出典を取得して data/ を作り直す
python3 collect.py --only akita-kumadas
python3 collect.py --no-write         # 取得と品質確認だけ
python3 validate.py                   # 生成物の検算
```

依存は `requests` と `openpyxl` だけです。

## Kaggle への公開

日次実行（`.github/workflows/collect.yml`）の最後に、`data/` と同じものを Kaggle に上げます。
`build_kaggle.py` が `_kaggle/` に一式（`sightings.csv`・`sightings.geojson`・出典ごとの帰属表示
`attribution.csv`・`summary.json`・説明文）を作り、`kaggle_published.py` が Kaggle の最新版と
`data/` の最新 commit を突き合わせて、違っていれば新しい版を出します。
データセットがまだ無ければ公開で新規作成します。

動かすには、リポジトリに次を設定します（未設定なら Kaggle の手順は飛ばされます）。

- Secrets: `KAGGLE_USERNAME`（`yasunorim`）と `KAGGLE_KEY`
- Variables: `KAGGLE_PUBLISH` = `true`

手動実行（Run workflow）で `publish` を付けると、変化が無くても今のデータで版を出します。

## スキーマ

| 列 | 意味 |
|---|---|
| `id` | `<出典 id>:<公開元の ID または行番号>` |
| `pref_code` / `pref` | 都道府県コード（JIS）/ 名称 |
| `occurred_at` | ISO8601。時刻が公開されていない出典は `YYYY-MM-DD` |
| `species` / `species_label` | `tsukinowaguma` `higuma` `inoshishi` `shika` `saru` `kamoshika` `bear` `unknown` |
| `category` / `category_raw` | `sighting` `trace` `damage` `injury` `capture` `unknown` と、公開元の原文 |
| `count` | 頭数（公開されていれば） |
| `municipality` / `place` | 市町村 / 地名・場所 |
| `lat` / `lon` | WGS84 |
| `note` | 公開元が書いている状況の説明 |
| `source_id` / `source_page` / `license` / `attribution` | 出典の追跡用 |

### 正規化で置いた仮定

黙って推測せず、ここに書き出します。

- **年の無い日付**: 宮城県の地図には「10月18日」のように年が無い点が 2,600 件あります。
  `sources.json` の `fiscal_year` を使い、**4 月以降はその年度、3 月以前は翌暦年**として補完します。
- **米国式の日付**: Google マイマップの書き出しは `10/23/2025` の形になります。
  日本の自治体データに 日/月/年 表記は観測されていないため、**月始まり**で解釈します。
- **獣種が列に無い出典**: 出典が単一の獣種しか扱っていない場合のみ、`species_default` で補います
  （北海道はヒグマ、本州の各県はツキノワグマ）。列がある出典は列を優先します。
- **午前・午後つきの時刻**: 「午後3時30分」は 15:30、「午前12時10分」は 0:10 と読みます。
- **ArcGIS の日付だけの値**: 時刻が別の列にある出典では、日付列の値が日本時間 0:00 か UTC 0:00（日本時間 9:00）なら
  日付だけの値とみなし、別列の時刻と組み合わせます。
- **月・日だけの日付**: 宮城県の令和8年度の表は月・日・時刻が別の列で年がありません。年度（2026）から、4 月以降は 2026 年、3 月以前は 2027 年とします。
- **東京都の区分**: `Witness` は目撃、`Filming`（カメラでの撮影）も目撃、`trace` は痕跡、`capture` は捕獲とします。
- **岐阜県の座標**: 令和2年度以降の Shapefile には座標系の定義（.prj）がありません。値は平面直角座標で、
  岐阜県に割り当てられた第 VII 系として緯度経度に変換しています。変換後の点の市町村ごとの中央値は、
  緯度経度で公開されている令和元年度の点と数 km 以内で一致しました（高山市・飛騨市は 0.6km）。
  年は表に無いので、リソース名の年度から補います。
- **個人の氏名**: 原文を残す列（市町村・場所・状況・区分の原文・獣種の原文）に人名が含まれる場合に備え、
  「○○氏」「○○宅」「○○さん宅」「○○さんが目撃」「「○○」さんという方」の形の氏名は
  `（個人名）` に置き換えて収録します。人に関する列（通報者・入力者など）は取り込みません。
  「農区長○○氏」のような肩書きは残し、氏名だけを伏せます。「目撃者宅」「帰宅」「藩主佐竹氏」のような一般語・歴史上の人物は
  置き換えません。迷う語は伏せる側に倒します。電話番号（全角数字を含む）・メールアドレスも伏せます。形の決まっていない書き方は取りこぼす可能性があります。
  `validate.py` は伏せ残しを検出すると失敗します。
- **単位つきの頭数**: 「2頭」「約3頭」は数として読みます。「2～3頭」「10頭以上」「数頭程度」のような幅のある書き方と「不明」は空にします。
- **判定できなかった値は捨てません**。`category_raw` に原文が残ります。

## ライセンス

- **コード**: MIT
- **データ**: 各出典のデータを**加工して作成**しています（列の統一・日付や区分の正規化・個人名の置き換え）。出典ごとにライセンスが異なります。収録しているのは CC BY（4.0 / 2.1 JP / 版の記載なし）、
  公共データ利用規約（PDL1.0、CC BY 4.0 互換）、宮城県の「出典を明記することを条件に…二次利用が可能」のいずれかで、
  `attribution` 列に表示すべき出典元が入っています。詳細と根拠は [`docs/licenses.md`](docs/licenses.md)。

公開元から「収録しないでほしい」という指摘があれば、**その出典を直ちに外します**。issue でお知らせください。

## 出典を追加するには

1. `sources.json` にエントリを足す（`adapter` は `csv` / `xlsx` / `arcgis` / `kml` /
   `pdf` / `pdf_bbox` / `bodik` / `ckan` / `ckan_shp` / `kviewer`）
2. `python3 collect.py --only <あなたの id> --no-write` で列の当たりを確認
3. 規約ページを実際に読み、`docs/licenses.md` に引用つきで判定を書く
4. `python3 validate.py` が通ることを確認して PR

新しい公開形式に当たったら `collectors/adapters.py` にアダプタを足してください。
